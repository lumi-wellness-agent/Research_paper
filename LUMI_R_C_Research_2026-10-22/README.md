# LUMI R/C 연구 논문 정리본

2026-10-22 기준으로 검증하고 분류한 웰니스 연구 자료입니다. 2026-10-23에 36편 근거 목록의 논문 9편(P30–P34, P37–P39, N26)을 마스터 목록에 추가했습니다. 2026-10-27에 S3 정신 피로 VAS(INS-MFVAS)의 형식 근거로 측정도구 체계적 고찰 1편(N27)을 추가했습니다(R1·R5에만 연결, 근거 arm·임베딩 대상 아님). 2026-10-29에 S1 목표 척도 BSRI의 원판 논문(N28, Marchetti 외 2018)을 추가했습니다(R1·R2·R5에 연결). 원문은 미확보이고, 대신 BSRI 개발자들이 쓴 척도 소개 문서(문항 · 채점 · 사용 조건)를 N28 이름으로 넣었습니다.

## 구성

- `00_original_PDF/`: 중복 없는 원본 PDF 77편과 N28 척도 소개 문서 1건
- `LUMI_R_C_논문목록_2026-10-22.xlsx`: RAG 목표(R1-R5)와 콘텐츠 유형(C01-C10) 매핑. `논문 유형` 열은 연구 설계 6범주(이론·개념 리뷰 / 체계적 고찰·메타분석 / 척도·측정도구 개발/검증 / 무작위 실험 / 준실험·비무작위 비교 / 관찰·설문·질적 연구)이고, 기존 자유 서술 라벨은 `세부 설계` 열에 보존했습니다. 범주 정의와 경계 사례는 `논문 유형 기준` 시트에 있습니다.
- `01_fulltext/`: 근거 레코드가 있는 논문 54편의 전문 텍스트(Docling 파싱). `<ID>.json`은 Docling 항목(제목 · 본문 · 표 Markdown · 쪽 번호)이고 `<ID>.md`는 섹션별로 읽는 보기입니다. BE(lumi-wellness-agent-be)가 근거 레코드 content로 쓸 원문 METHODS · RESULTS 발췌를 고를 때 읽습니다(`make parse-papers` · `make extract-excerpts`). P05 · P26은 스캔 PDF를 RapidOCR로 읽은 결과입니다(쪽 원본 해상도, 숫자 토큰 정확도 0.96 — Apple Vision 0.82 · Tesseract 0.76 · EasyOCR 0.56보다 높았습니다). 그래도 오인식이 남아 BE는 쪽 이미지와 대조해 교정한 발췌만 씁니다. 출판사 구독본의 전문이므로 이 비공개 저장소 밖으로 옮기지 않습니다.
- `미확보_논문_직접검색_목록_2026-10-22.xlsx`: 현재 미확보 논문 7편과 DOI·검색 문구
- `LUMI_측정도구_프로토콜_2026-10-23.xlsx`: 회복 세션 워크플로우(사전 측정 → 활동 노드 1개 → 사후 측정 → replan)의 BE 테이블 초안. 측정도구(척도 14편 → instrument 13 — BSRI는 원판 N28과 측정 불변성 N25 두 편 — + S3 임시 도구 INS-MFVAS 1, VAS 형식 근거 N27), Care Protocol 후보(활동 노드 21개), 프로토콜별 근거 arm 65건, (프로토콜 × 지표) 등급 규칙. 용어는 활동 노드(설계·BE) / 중재(논문) / 콘텐츠(활동이 쓰는 재료)로 구분합니다.

파일명 앞의 ID는 마스터 목록 ID입니다. 36편 근거 목록(저장소 루트 `LUMI_RAW데이터 링크.xlsx`의 `34편 근거 재분류` 시트)과는 번호 체계가 달라, 두 ID의 대응은 그 시트의 `R/C 마스터 ID`·`레포 PDF 파일명` 열에서 확인합니다. P30–P34는 두 목록의 ID가 같습니다. `P31`은 UWE 저장소의 저자 원고본(표지·Table 1–4 포함)이라 출판본과 쪽 배치가 다릅니다. `N28`의 PDF는 2018 논문 원문이 아니라 BSRI 개발자들이 쓴 척도 소개 문서(문항 · 채점 · '연구 목적 무료 사용, 2018 논문 인용' 조건)입니다. 논문 원문은 미확보라 원문 확보 개수에 넣지 않습니다.
